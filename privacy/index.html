プライバシーポリシー

ツムギ（以下「私たち」）が提供する無料の Web ツールと、スマートフォン・PC 向けのアプリ（「ひとふで つむぎ」など。以下「本サービス」）での、情報の扱いについて定めます。

1. 集める情報

本サービスは、氏名・メールアドレス・位置情報・端末の識別子などの個人情報を集めません。アカウントの登録もありません。

2. 端末の中に保存する情報

入力した内容やゲームの進み具合は、お使いの端末の中（ブラウザの localStorage、アプリの保存領域）にだけ保存します。私たちのサーバーや第三者には送信しません。アプリを削除するか、ブラウザのサイトデータを消すと、保存した内容も消えます。

3. 外部への送信・広告・解析

本サービスは、広告の配信、アクセス解析、クラッシュの報告などのための外部のサービス（SDK）を使っていません。将来これらを使う場合は、送信する情報の内容・送信先・目的をこのページで事前にお知らせします。

4. Web サイトの配信

Web ツールは GitHub Pages で配信しています。配信の仕組み上、GitHub がアクセスの記録（IP アドレスなど）を扱うことがあります。詳しくは GitHub のプライバシーに関する声明をご覧ください。

5. お子さまの利用

本サービスは個人情報を集めないため、お子さまも安心して使えます。

6. お問い合わせ

BOOTH のショップ（tsumugi-ops.booth.pm）のメッセージ機能からご連絡ください。

7. 改定

内容を変える場合は、このページでお知らせします。
